# Assetto Corsa Live Telemetry Mod

Mod for Assetto Corsa that captures in-game data and broadcasts it via UDP. Works best with [AC Live Server](https://github.com/Kristex95/assetto-corsa-live-telemetry-server)

## Features

- Track map points
- Live leaderboard
- Pit indicators

## Additional Info

- Default port: 22566
